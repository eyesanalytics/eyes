# eyes-types

The shared TypeScript types of [`eyes-react`](https://www.npmjs.com/package/eyes-react), [`eyes-next`](https://www.npmjs.com/package/eyes-next) and the [Eyes](https://eyes.dev) browser tracker: the events it sends and the options it takes. You do not need to install it yourself, because the SDKs depend on it.
